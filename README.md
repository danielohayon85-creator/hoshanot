# הושענות — אפליקציית קריאה עם גלילה איטית

אפליקציית ווב סטטית (ללא שרת) שמציגה את **ההושענות של היום**, לפי נוסח, עם **גלילה אוטומטית איטית** — כדי שאפשר יהיה לעקוב בידיים תפוסות בלולב ובאתרוג.

## מה יש בה
- **זיהוי היום אוטומטי** לפי הלוח העברי (`Intl` עם לוח `hebrew`, בלי ספריות). מחוץ לסוכות — מוצג כמה ימים נשארו, ואפשר לעיין בכל יום.
- **סדר ההושענות הנכון** לאשכנז ולספרד לפי היום בשבוע שבו חל יום טוב ראשון (ב׳ / ג׳ / ה׳ / שבת), כולל אום נצורה בשבת. בעדות המזרח — לפי מספר היום, ובשבת הושענות לשבת. בחב"ד — סדר קבוע לפי מספר היום, ובשבת אין אומרים הושענות.
- **4 נוסחים:** אשכנז · ספרד · עדות המזרח · חב"ד (הבחירה נשמרת).
- **גלילה איטית:** 15 רמות מהירות, מהירות שמתאימה את עצמה לגודל הגופן, עצירה בלחיצה על הטקסט, עצירה זמנית כשנוגעים במסך.
- **קו מיקוד** שמסמן איפה קוראים · **המסך נשאר דלוק** בזמן גלילה (Wake Lock) · **מסך מלא** · **הגדלת גופן**.
- **הושענא רבה:** מעבר מהיר בין ההקפות.
- **מצב כהה**, מותאם לנייד, ו**עובד בלי אינטרנט** אחרי טעינה ראשונה (Service Worker) — ניתן להתקין כאפליקציה במסך הבית.

## הרצה
אין תלויות ואין בנייה. מספיק שרת קבצים סטטי:

```bash
cd hoshanot   # תיקיית ה-repo
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

פרסום: כל אחסון סטטי (GitHub Pages, Netlify, Render Static Site) — ב-GitHub Pages: Settings → Pages → Deploy from branch → `main` / `(root)`.

## מדידת שימוש
המדידה נעשית עם [GoatCounter](https://www.goatcounter.com): בלי עוגיות, בלי מידע אישי ובלי צורך בבאנר הסכמה. כדי להפעיל אותה:
1. פותחים חשבון חינמי ב-goatcounter.com, למשל בשם `hoshanot`. הדשבורד יהיה בכתובת `hoshanot.goatcounter.com`.
2. ב-`app.js` מוגדר שם החשבון: `const GOATCOUNTER_CODE = 'danielohayon85';` (דשבורד: danielohayon85.goatcounter.com)

מה נמדד:
- כניסות ומבקרים ייחודיים (אוטומטי, כולל מכשיר ומדינה).
- `nusach-ashkenaz` / `nusach-sefard` / `nusach-edot`: איזה נוסח היה בשימוש.
- `scroll-play`: הפעלת גלילה. `scroll-speed-N`: המהירות שבה התחילו.
- `open-installed`: פתיחה מאפליקציה מותקנת. `installed`: התקנה במסך הבית (אנדרואיד/כרום).

כל אירוע נספר פעם אחת לכל כניסה, כך שהמספרים משקפים אנשים ולא לחיצות. כניסות בלי רשת לא נספרות.
